## Issues

[GitHub Issues](https://github.com/renniyy/george-gui-search/issues) is the bug and feature tracker. Use the issue templates so reports are actionable:

- **Bug reports**: Node version, MCP client, exact tool call JSON, expected vs actual, stderr of a manual `npx george-gui-search` run.
- **Feature requests**: the problem you're solving, not just the solution you imagine.

## Security

Vulnerabilities go through [GitHub security advisories](https://github.com/renniyy/george-gui-search/security/advisories) — never public issues. See [SECURITY.md](SECURITY.md).

## Response expectations

This is a maintained open-source project, not a support contract: bugs with complete reproductions are usually triaged within a week; complex features are scheduled against the [roadmap](docs/ROADMAP.md).

## Commercial use

The MIT license permits any use. If George ships inside your product, a visible credit ("UI generated with GEORGE GUI @Search") is appreciated but never required.
